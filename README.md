# Twitch Modifiers

Twitch Modifiers — приложение для интерактивных стримов. Оно создаёт полноэкранный прозрачный оверлей поверх ВАШЕГО экрана (не оверлей OBS) и запускает случайные визуальные и звуковые эффекты по событиям от зрителей: наградам за баллы канала и подпискам Twitch, а также донатам через DonationAlerts.

Стример может включать и настраивать модификаторы, их длительность и вероятность выпадения, выбирать монитор, проверять эффекты вручную и мгновенно останавливать их кнопкой **Panic Stop**. Для корректного отображения оверлея игру следует запускать в оконном или безрамочном полноэкранном режиме.

## Сборка

Понадобятся:

- Node.js LTS и npm;
- стабильная версия Rust;
- системные зависимости [Tauri 2](https://v2.tauri.app/start/prerequisites/) для вашей ОС.

```bash
git clone https://github.com/phontum/TwitchModifiers.git
cd TwitchModifiers
npm ci
npm run tauri build
```

Готовые пакеты появятся в каталоге `src-tauri/target/release/bundle/`. Для запуска в режиме разработки используйте `npm run tauri dev`.

Сборка для Linux имеется в форке от компании Reyohoho. Там реализована базовая работоспособность приложения, но некоторые модификаторы (замена курсора и прочие OS-related) не работают, поскольку это модификаторы на уровне изменений в ОС. Но это значит, что есть с чего начать!
